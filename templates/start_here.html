Start Here

This is a public, evidence-first portfolio for the skills being built in ~/tech-skill-up/. The target roles are Systems Administrator and NOC Technician, and the through-line is a four-CompTIA-cert journey (Network+ → Security+ → Linux+ → Server+) with each cert anchored to a homelab project.

First reviewer paths

  • Portfolio — the homelab operations projects, this site as a self-hosting artifact, and the certification track.
  • Writing — homelab, networking, Linux, and defensive-security writeups as artifacts become evidence-backed.
  • About — role focus, portfolio pillars, approach, and non-claims.
  • Archive — the pruned GeistScope reference notes; not a primary reviewer path.

Evidence standard

Resume-facing artifacts should show the starting state, target state, tools and components, commands or configs used, real evidence, what broke or could break, verification, cleanup or rollback notes, what I understand now, and what I still need to learn. Nothing is fabricated: no invented command output, timestamps, or a certification claimed before it is passed.

Portfolio pillars

  • Homelab & Proxmox: node baseline, VM fleet, validated backup/restore, and monitoring.
  • Networking: internal DNS, subnet/VLAN maps, request-path documentation, and CLI diagnostics (Network+).
  • Linux / SysAdmin: systemd, journald, users/permissions, service ops, and small automation (Linux+).
  • Security (defensive, small): security headers, SSH hardening, TLS, and auth-log detection on owned scope (Security+).
  • Certification journey: Network+ → Security+ → Linux+ → Server+ by January 2027, each tied to a homelab project.

What this portfolio is not claiming

This site is not claiming production-grade infrastructure, enterprise network ownership, senior DevOps/SRE maturity, a NOC operated 24/7, penetration testing, AI infrastructure engineering, or advanced Rust backend expertise. Those labels can wait until the public artifacts support them directly.
