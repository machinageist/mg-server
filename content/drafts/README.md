# Drafts

Unlike its siblings `content/posts/` and `content/pages/`, this directory is
**not scanned or routed** by anything in `src/`. It holds two kinds of
not-yet-public material, both awaiting a long-form interview process where
Jeff retains ownership of the finished content:

- writing pulled out of publication and kept verbatim, awaiting a rewrite
  (e.g. `geistscope-retrospective.md`);
- bare ideas that were never published anywhere, staged as a backlog for the
  same interview process to develop from scratch (e.g.
  `ideas-from-digital-liberty.md`).

Nothing here is live. Moving a file back into `content/posts/` is what makes
it public again.
