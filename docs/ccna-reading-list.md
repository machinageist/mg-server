# CCNA reading list: moved

**Moved:** 2026-10-05

The reading list and the note files now live with the course, in
`~/mg-coreforge/ccna/course/`:

- `notes/ORDER.md`: the order to take notes in.
- `notes/READING-LIST.md`: the whole course's reading on one page.
- `notes/NN-<slug>.md`: one blank note file per topic. A file named after a draft page
  under `content/pages/` holds the notes for that page.
- `weeks/<week>/reading.md`: each week's videos, Odom chapters, objectives, and primary
  sources. The entries for the 14 draft pages moved here unchanged.

Notes no longer go in `content/drafts/ccna-notes/`.
